# inovacc-core/.github
<!-- rev:001 (RFC 3339) 2026-10-17T22:39:55Z -->

Organization-wide defaults for every `inovacc-core` repository: GitHub uses these files for any repository that has no
file of its own.

| File | What it is |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | how a change reaches `main`: branch, pull request, CI, review, squash merge |
| [.github/pull_request_template.md](.github/pull_request_template.md) | the pull request template |
| [SECURITY.md](SECURITY.md) | how to report a vulnerability privately |
| [docs/DOCUMENTATION-STANDARD.md](docs/DOCUMENTATION-STANDARD.md) | the document set every Worker, container and library carries |

The developer-surface rule (contracts, OpenAPI, SDKs, portal, surface changelog) is in
`inovacc-core/developer/docs/DEVELOPER-SURFACE.md`.
